# Session Logger

A moderator tool for usability tests: timed tasks, success and error logging, CSV export.

**Live demo:** `https://YOUR-USERNAME.github.io/session-logger/` (after enabling GitHub Pages)

## Features
- High-precision task timer
- One-tap success, fail, and error counting
- Live success rate, mean time, mean errors
- Data persists in localStorage; export to CSV

## Run locally
No build step. Open `index.html` in a browser.

## Skills shown
UX research, event-driven JavaScript, localStorage, data export, HTML escaping
